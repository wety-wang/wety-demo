## 管理规则

- 当月进行中的任务建在 `docs/90-工作区/<YYYY-MM-DD-主题>/`，包含 `task_plan.md`、`findings.md`、`progress.md`。

- 每月初将上月已完结的任务目录整体移入 `archive/YYYY-MM/` 并同步更新本索引。
